# Verizon Group Marketing Site

A Next.js 14 + TypeScript + Tailwind CSS site for Verizon Group, showcasing Moodle solutions, hosting, and cloud services.

## Getting Started

1. Install dependencies

```bash
npm install
```

2. Run the development server

```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) to view the site.

## Environment

Optional: set `NEXT_PUBLIC_GOOGLE_CALENDAR_BOOKING_URL` to override the booking link used on the Book Meeting page.

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion for subtle animations
- Heroicons & Lucide for iconography
