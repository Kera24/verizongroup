# Verizon Group Website

Marketing site for Verizon Group built with Next.js 14, TypeScript, and Tailwind CSS. The site highlights services for Moodle, hosting, cloud infrastructure, and managed support.

## Getting started

```bash
npm install
npm run dev
```

Set `NEXT_PUBLIC_GOOGLE_CALENDAR_BOOKING_URL` to change the booking link on the Book Meeting page.
